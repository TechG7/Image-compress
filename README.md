# 🖼️ Image Compressor & Converter

A lightweight, web-based tool designed to compress and convert images directly in your browser without losing quality.

## ✨ Features
* **Image Compression:** Reduce image file sizes efficiently.
* **Format Conversion:** Convert images to different formats easily.
* **Fast & Client-Side:** Processing happens entirely in the browser for maximum privacy and speed.
* **No Server Required:** Built with pure HTML, CSS, and JavaScript.

## 💻 How to Use
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Upload your image, select desired compression/conversion settings, and download the output file.
